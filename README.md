# Yogesh Anil Patil — Data & BI Analyst Portfolio

A modern, zero-build-dependency personal portfolio built with semantic HTML5, custom CSS3 (**Obsidian Slate × Warm Champagne Gold × Signal Emerald** theme with instant **Ivory Light Mode** switcher), and vanilla ES6+ JavaScript.

## Features
- **Unique Editorial Analytics Theme:** Obsidian dark mode + Ivory light mode toggle persisted in `localStorage`.
- **Interactive Hero BI Telemetry Workbench:** Live switcher between `KPI Suite`, `SQL View`, and `DAX` measures.
- **Filterable Project Showcase + Case Study Modal:** Filter by `All`, `BI & Dashboards`, `SQL & Modeling`, or `Engineering`, plus an interactive `<dialog>` modal featuring all 3 real Spotify Power BI dashboard screenshots (`Overview`, `Artists`, `Songs`).
- **Complete Verified Credentials & Experience Timeline:** Synchronized with your latest 1-page ATS Resume PDF (`assets/Yogesh_Patil_Data_Analyst_Resume.pdf`) and LinkedIn profile.

## Quick Local Preview
Open `index.html` directly in Chrome or Edge, or run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Free Deployment (2 Minutes)
### Option A — Deploy on Vercel
1. Push the `Portfolio` folder to a new GitHub repository (e.g., `yogesh-patil-portfolio`).
2. Go to [vercel.com/new](https://vercel.com/new), import the repo, keep **Framework Preset: Other**, and click **Deploy**.

### Option B — Deploy on GitHub Pages
1. Push the `Portfolio` folder to a public GitHub repo.
2. Go to **Settings → Pages → Build and deployment → Source: Deploy from a branch (`main` / `root`)** and click **Save**.
